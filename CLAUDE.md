# CLAUDE.md

Guidance for Claude Code when working in this repository.

## Working agreement

- **Committing is allowed**, but ask for **explicit permission before every commit**.
  Never commit without a clear go-ahead.
- **Do not include a `Co-Authored-By` tag** in commit messages.
- **Never push or deploy.** Do not ask about it either — if the user wants an
  exception, they will say so explicitly.
- Work in **small, self-contained, committable changes**. Prefer many small
  commits over one large one.

## Commit messages

- Follow **Conventional Commits** (`feat:`, `fix:`, `chore:`, `docs:`,
  `refactor:`, `test:`, etc.).
- Keep paragraphs short and easy to read.
